# Мои карты — кошелёк скидочных карт

Приложение для Android 16 (оптимизировано под vivo X200 Pro mini): хранит скидочные и бонусные
карты, добавляет их по штрихкоду или QR-коду с камеры или со скриншота, само определяет магазин
и показывает цифровую копию карты с кодом для кассы. Работает офлайн; через интернет один раз
загружает логотип и цвета магазина.

## Возможности

- **Сканирование камерой** — рамка в пропорциях настоящей карты, фонарик, код засчитывается после
  двух одинаковых чтений подряд (защита от ошибок).
- **Скриншот или фото** — кнопка «Из скриншота» или «Поделиться → Мои карты» прямо из галереи.
  Длинные скриншоты просматриваются по фрагментам, если код мелкий.
- **Распознавание магазина** — офлайн по четырём признакам:
  1. содержимое кода (в QR часто есть адрес сайта магазина);
  2. надписи на карте/скриншоте (встроенное распознавание текста с поправкой на кириллицу);
  3. правила номеров из каталога (`numberPatterns` в `brands.json`);
  4. **самообучение**: если номер похож на уже сохранённую карту (общий префикс), приложение
     предлагает тот же магазин — чем больше карт, тем точнее.
  Если уверенности нет, показываются варианты и поиск по каталогу из 48 сетей.
- **Цифровая копия** — карта в цветах магазина, крупный штрихкод/QR на белом фоне, при открытии
  яркость экрана максимальная и экран не гаснет. Номер копируется нажатием.
- 13 форматов: QR, EAN-13/8, UPC-A/E, Code 128/39/93, Codabar, ITF, PDF417, Aztec, Data Matrix.
- Ручной ввод, редактирование, выбор цвета, заметки, поиск, резервная копия в файл и восстановление.
- Дизайн в духе OriginOS: светло-серый фон, белые скруглённые блоки, синий акцент, крупные заголовки,
  упругие анимации нажатий, «стопка» карт, тёмная тема. Шрифт системный — на vivo это шрифт OriginOS.

## Оформление магазина из интернета

При добавлении карты в блоке **«Оформление»** нажмите «Найти магазин в интернете» и напишите
название. Приложение:

1. ищет магазин в открытой базе **Wikidata** (база Википедии — без ключей и регистрации)
   и показывает варианты;
2. по выбранному варианту берёт **официальный сайт** и **логотип**;
3. с сайта магазина берёт **фирменный цвет** (meta theme-color) и иконку, если логотипа нет;
4. если сайт цвет не указал — вычисляет его по логотипу;
5. сохраняет логотип и цвета **на телефоне**: следующие карты этого магазина оформятся сами,
   без интернета (достаточно, чтобы совпало название или магазин определился при сканировании).

Если магазина нет в Wikidata — можно указать его сайт вручную. В интернет уходит только название
магазина или адрес сайта; номера карт никуда не передаются.

Дополнительно: если в QR-коде карты есть ссылка, приложение проходит по ней и определяет магазин
по сайту, на который она ведёт.

Интернет можно полностью выключить: меню «⋯» → **Настройки**.

## Без интернета

- Модели распознавания (ML Kit «bundled») встроены в APK и **не требуют сервисов Google Play** —
  важно для китайской прошивки OriginOS, где их нет.
- Без сети работает всё, кроме поиска нового оформления: офлайн-каталог, распознавание текста,
  самообучение, сохранённые логотипы.
- Карты, логотипы и оформления хранятся только в памяти приложения; резервная копия в файл
  включает и логотипы.

## Как получить APK

### Вариант 1 — без установки программ (GitHub)
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** — сборка запустится сама (≈5–8 минут).
3. В завершённом запуске скачайте артефакт **MyCards-apk**, распакуйте и установите APK на телефон.

### Вариант 2 — Android Studio
1. Установите Android Studio (последнюю версию) и откройте папку `MyCards`.
2. Дождитесь синхронизации Gradle (Studio сама скачает Android SDK 36).
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)** или запустите кнопкой ▶ на подключённом телефоне.

### Установка на vivo
- Разрешите установку из неизвестных источников, когда система спросит.
- Для запуска из Android Studio: Настройки → О телефоне → 7 раз нажать «Версия ПО»,
  затем включить «Отладка по USB» в «Для разработчиков».

## Как дополнить каталог магазинов

Файл `app/src/main/assets/brands.json`:

```json
{
  "id": "mystore",
  "name": "Мой магазин",
  "category": "Продукты",
  "aliases": ["мой магазин", "moy magazin"],
  "domains": ["mystore.ru"],
  "colors": ["#3E6BFF", "#1E3BB0"],
  "numberPatterns": ["^2771\\d{9}$"]
}
```

`numberPatterns` — регулярные выражения для номеров карт сети; если знаете, как начинаются номера
карт конкретного магазина, впишите их сюда. Без них работает самообучение на ваших картах.

## Структура

```

├── MainActivity.kt              навигация, приём скриншотов через «Поделиться»
├── data/                        модели, хранилище (JSON), каталог магазинов
├── recognition/CardRecognizer   офлайн-определение магазина
├── scan/                        ML Kit (камера/изображения), генерация кодов (ZXing)
└── ui/                          тема OriginOS, компоненты, экраны
```
